# Smith & Devil recovered source

This is the clean handover branch for the recovered Smith & Devil website.

It contains editable Next.js source, current image and brand assets, required font assets, Netlify build configuration and browser QA checks.

It deliberately excludes the old compiled deployment snapshot, exported route HTML and recovery-only parity fixtures.

The recovery branch `source-rebuild` passed:
- production build
- 24-route content/media parity
- desktop/mobile browser QA

Production has not been switched to this branch.
